Verkettete Liste

Jeder Knoten enthält Daten und einen Zeiger auf den nächsten Knoten. Der Anker zeigt auf den ersten Knoten, der letzte zeigt auf NULL.

Startzustand: 3 Knoten.
Darstellung (Erwartungshorizont-Stil)

Stapelspeicher

LIFO-Prinzip: Nur das oberste Element ist zugänglich. push legt oben auf, pop nimmt von oben weg.

Stapel ist leer.
Python-Code

Warteschlange

FIFO-Prinzip: Wer zuerst kommt, wird zuerst bedient. enqueue reiht hinten ein, dequeue entfernt vorne.

Warteschlange ist leer.
Python-Code

Baum

Ein sortierter Binärbaum: Werte kleiner als ein Knoten stehen links, größere rechts. Neue Werte werden an der passenden Stelle eingefügt.

Startbaum mit 3 Knoten.
