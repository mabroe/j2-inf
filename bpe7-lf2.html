Warum zwei Schleifen? Die innere Schleife (j) vergleicht bei einem einzigen Durchgang alle benachbarten Paare von vorne bis hinten – dabei wandert das größte verbleibende Element höchstens eine Position nach hinten. Damit wirklich alle Elemente an ihre endgültige Position kommen, muss dieser Durchgang mehrfach wiederholt werden – dafür ist die äußere Schleife (i) da.
Bereit – klickt „Nächster Schritt“.
Richtig geraten: 0 von 0

Selection Sort

Wichtig: Es gibt keinen eingebauten Befehl, der euch „das kleinste Element“ verrät. Ihr müsst das Array Schritt für Schritt selbst durchgehen und dabei den Index des bisher kleinsten Werts mitführen – min(array) ist hier nicht erlaubt.
Code
Ausgabe (Konsole)
Noch keine Ausgabe.
Variablen
Struktogramm
Warum zwei Schleifen? Die innere Schleife (j) durchsucht einmal den kompletten noch unsortierten Rest des Arrays, um das kleinste Element darin zu finden – mehr leistet ein einzelner Durchlauf nicht. Damit jede Position im Array befüllt wird, muss diese Suche für jede Position einmal wiederholt werden – dafür ist die äußere Schleife (i) da.
Bereit – klickt „Nächster Schritt“.
Richtig geraten: 0 von 0

Bubble Sort vs. Selection Sort

Beide sortieren mit zwei verschachtelten Schleifen, aber die innere Schleife macht etwas anderes: Bubble Sort vergleicht und tauscht bei jedem Schritt sofort; Selection Sort vergleicht nur und tauscht am Ende der inneren Schleife genau einmal.
