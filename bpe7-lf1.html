2. Element einfügen

Ein neuer Wert soll an einer bestimmten Stelle stehen, ohne bestehende Werte zu überschreiben – dafür wandert er, an letzter Stelle angehängt, per Vertauschen Schritt für Schritt an seine richtige Position.

Code
1array = []
das Array, in das eingefügt wird (Zustand vor dem Einfügen)
2neuer_wert = input("Wert: ")
einzufügender Wert (Eingabefeld „Wert“)
3index = int(input("Index: "))
Position, an der der Wert stehen soll (Eingabefeld „Index“)
4array.append(neuer_wert)
neuen Wert zunächst ganz hinten anhängen
5for i in range(len(array) - 1, index, -1):
läuft rückwärts von hinten bis index+1
6temp = array[i - 1]
Wert davor zwischenspeichern
7array[i - 1] = array[i]
neuen Wert eine Position nach vorne tauschen
8array[i] = temp
zwischengespeicherten Wert zurückschreiben
Struktogramm
Deklaration und Initialisierung: array = []
Einlesen: neuer_wert
Einlesen: index
Zuweisung (Anhängen): array[len(array)] = neuer_wert
Wiederhole von i = len(array) - 1 solange i > index, Schrittweite -1
Deklaration und Initialisierung: temp = array[i-1]
Zuweisung: array[i-1] = array[i]
Zuweisung: array[i] = temp
Gebt Wert und Index ein und klickt „Einfügen starten“.

3. Element entfernen

Der Wert an einer bestimmten Stelle soll verschwinden – dafür rücken alle folgenden Werte einen Platz nach vorne, dann wird der letzte (jetzt doppelte) Platz entfernt.

Code
1array = []
das Array, aus dem entfernt wird (Zustand vor dem Entfernen)
2index = int(input("Index: "))
Position des Werts, der entfernt werden soll (Eingabefeld „Index“)
3for j in range(index, len(array) - 1):
läuft vorwärts von index bis vorletzter Platz
4array[j] = array[j + 1]
folgende Werte eine Stelle nach vorne schieben
5array = array[0 : len(array) - 1]
letzten (jetzt doppelten) Platz entfernen
Struktogramm
Deklaration und Initialisierung: array = []
Einlesen: index
Wiederhole von j = index solange j < len(array) - 1, Schrittweite 1
Zuweisung: array[j] = array[j+1]
Zuweisung: array = array[0 : len(array) - 1]
Gebt einen Index ein und klickt „Entfernen starten“.
