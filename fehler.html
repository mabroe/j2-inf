So liest man eine Fehlermeldung

Python nennt in der Meldung, wo und was schiefgelaufen ist. Lies sie von unten nach oben:

Traceback (most recent call last):  File "main.py", line 3, in <module>    print(array[3])          ~~~~~^^^IndexError: list index out of range
  1. Letzte Zeile zuerst: Fehlertyp (IndexError) und Meldung (list index out of range) sagen, was passiert ist.
  2. Zeilennummer: line 3 zeigt, wo Python den Fehler bemerkt hat. Die Ursache kann aber davor liegen (z. B. fehlende Klammer, nie gesetzte Variable).
  3. Codezeile darunter: Dort die beteiligten Variablen und Werte prüfen.
  4. Fehlertyp im Katalog nachschlagen (Reiter „Fehlertypen“) und die typischen Ursachen durchgehen.

Hinweis: Bei SyntaxError und IndentationError gibt es keinen Traceback mit mehreren Zeilen – das Programm läuft gar nicht erst los. Der genaue Wortlaut der Meldungen kann je nach Python-Version leicht abweichen.

Fehler systematisch beheben – in 7 Schritten

  1. Ruhe bewahren, Meldung vollständig lesen. Nicht raten, nicht wahllos ändern.
  2. Fehlertyp + Meldung + Zeilennummer notieren. Was wurde erwartet, was ist passiert?
  3. Stelle ansehen – und eine Zeile davor. Bei Syntaxfehlern liegt die Ursache oft davor.
  4. Werte sichtbar machen: print(variable) bzw. print(type(variable)) vor der Fehlerzeile, oder Schreibtischtest mit kleinem Beispiel (z. B. 3 Elemente).
  5. Hypothese bilden, genau EINE Sache ändern. Nicht mehrere Dinge gleichzeitig ändern.
  6. Erneut testen – auch Randfälle: leeres Array, ein Element, erstes/letztes Element, Zahl 0, negative Zahlen.
  7. Aufräumen: Hilfs-prints entfernen und kurz notieren, was die Ursache war – damit der Fehler nicht noch einmal passiert.

Typische Abitur-Falle: Fehler in vorgegebenem Code finden

Wenn in der Prüfung Code oder Struktogramm mit Fehler vorgegeben ist: Mit einem kleinen Beispiel von Hand durchlaufen (Schreibtischtest), Variablenwerte pro Schritt notieren, die Stelle benennen, an der Erwartung und Ergebnis auseinanderlaufen, und die Korrektur begründen.
